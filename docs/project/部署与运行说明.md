# 部署与运行说明

本次首次完整上线统一按 [运行手册](../../deploy/README.md) 和 [迁移核查单](../../deploy/MIGRATIONS.md) 执行。模板位于 `deploy/`，本轮事实与验证证据见 `AI_WORKLOG/2026-11-17-deploy.md`。旧同步部署说明仅作历史参考。

部署为单台服务器、一个Java后端及唯一worker，同机回环Python与Redis。先停旧应用、备份并验证、执行增量迁移，再按Redis→Java（worker关闭）→Python→同批前端→冒烟→启用唯一worker的顺序发布。不得把含DROP的初始化脚本用于云库升级。

旧公开JWT固定密钥已在Git历史中，旧线上版本当前存在令牌伪造风险。新版本要求独立随机JWT_SECRET，所有用户上线后需重新登录。实际连接信息和凭据由用户在终端管理，不写入本地交付文件或聊天。每一步服务器/云库写入和push均需明确授权。
