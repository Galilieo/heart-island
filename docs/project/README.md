## 常用查找

- 查数据库：先看 `04-数据库设计说明书.md`，再核对 `../../sql/xinyu.sql`。
- 查接口：先看 `05-接口设计说明书.md`，再核对后端 Controller 和前端 `src/api/`。
- 查前端页面：先看 `07-前端界面与交互设计说明.md`，再核对 `../../xinyu-vue/src/views/`。
- 查测试：先看 `08-测试说明书.md`，再执行实际命令验证。
- 写简历：先看 `10-项目总结与后续规划.md`，但不要夸大未实现能力。

## 内容边界

- `01-03` 更偏说明项目背景和整体结构，不适合作为接口或字段的唯一依据。
- `04-05` 是数据和接口参考，但仍要以 `sql/xinyu.sql`、Controller、DTO、VO 为准。
- `06-07` 可用于讲实现链路和前端组织，但不要把“设计目标”当成“已完全实现”。
- `08-09` 中的命令需要按当前本机环境验证，尤其是数据库密码、AI API 配置和端口。
- `10-11` 包含总结、规划和简历表达，适合讲项目，但未来规划不能说成已完成。

## 维护建议

- 新功能完成后，至少同步接口、数据库、测试或总结中相关部分。
- 如果只是开发期草稿，先放到 `../../ops/features/`，确认实现后再沉淀到本目录。
- 文档中出现“已完成”时，最好能对应源码路径、SQL 或验证结果。
- 文档调整尽量小步提交：先改入口和索引，再改单篇正文，避免一次性重写整套文档。
