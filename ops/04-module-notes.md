# 04 模块笔记

更新：2026-11-18。只记仍然有用的模块边界与注意事项；完整规则见各功能契约。

## 用户与权限

- 前端保存 token，后续请求带 `token` 头；后端从 token 取当前用户，不信任前端传入的 `userId`。
- `AuthInterceptor` 逐次读取用户：禁用账号 403；`/admin/**` 要求 ADMIN。社区列表、详情、回复列表允许匿名读取（`mine=true` 除外）。
- 只有 USER 与全站 ADMIN，没有社区版主。

## 心情记录与 AI 回应（[1a 契约](features/ai-reply-service-v1a.md)）

- 保存与 AI 生成分离：记录先落库，`ai_reply_enabled` 为真时写 `ai_job`，由 worker 异步执行；请求线程不等待模型。
- 每次修改递增 `content_version`；任务按来源版本条件提交，修改／删除后的迟到结果一律拒绝。
- 失败不写兜底文字冒充 AI 回复；手动重试复用冷却与容量门禁，不自动付费重试。
- 危机规则命中走固定 SUPPORT，`model_called=false`。

## 近期回顾与周报（[回顾契约](features/mood-review.md)）

- 统计永远由 Java 计算并存快照，模型输出中的数字不被读取；只发送开启 AI 的记录，内部别名 `rN`，不发数据库 ID。
- GET 不写库、不调用模型；生成按用户行锁去重，来源指纹变化即过期，删除来源会隐藏旧信正文。
- 与心情回复共用 worker 与容量上限，心情任务优先领取。

## 匿名社区与治理（[举报与分页契约](features/community-report.md)）

- 对外不返回作者 ID，只返回 `mine`；隐藏内容仅作者可见并显示原因。
- 帖子 AI 回应在请求内同步生成，用生成代次防止旧结果回写；互动计数只更新对应列。
- 列表分页，点赞／收藏状态按页批量查询；新增列表接口时避免逐条查询。
- 举报按对象聚合，后台裁决加锁；历史 `status=0` 无法区分作者删除与管理员隐藏，保留原值。

## 限流（[Redis 限流契约](features/redis-rate-limit.md)）

- 付费调用入口在准入事务外预检额度，只在“确定会产生调用”时扣；危机分支不扣；已扣不退。
- Redis 故障降级为本机计数并定时重试恢复；超额 429 带 `Retry-After`。

## 后台管理

- 新增可运营模块时，考虑后台查询、筛选、启用禁用与详情页；管理员能看到的原文范围要在隐私页同步告知。

## 后续维护方式

- 新模块上线后在本文件补一段“模块边界”和“注意事项”，细节写进功能契约。
- 只记录仍然有用的工程判断，不记录流水账。
