# features 目录说明

这里存放心屿后续功能的初版规划。它不是最终实现说明，而是开发前给人和 Agent 对齐用的工作草稿。

## 使用方式

1. 新功能先复制 `feature-template.md`。
2. 填写目标、场景、前后端、数据库、API、自测。
3. 让 Agent 基于该文档输出开发方案。
4. 确认后再进入代码修改。
5. 功能上线或废弃后，在文档顶部标记状态。
